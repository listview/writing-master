## 1. 选择原则

先确定读者打开作品时最稳定的期待，再确定叙事模式。模式不是题材标签，而是章节持续提供乐趣的方式。以下模式可以跨题材迁移；修炼、宗门、战斗等词只是奇幻示例，写作时应换成当前作品的事实。

每部作品选择一个主模式。只有在两种模式能服务同一主线时才添加一个副模式。模式切换必须由剧情阶段变化触发，不按作者临时兴趣切换。

## 2. 快节奏升级

### 核心承诺

主角快速解决危险，获得可见资源，形成新的能力组合，并进入更高层级的冲突。

### 章节发动机

> 威胁/任务 → 判断敌我差距 → 利用能力或环境 → 击破 → 收获 → 新层级

### 写法

- 让主角的能力表现为解决问题的方式，而非面板播报。
- 在升级前安排准备或资源来源，在升级后立刻安排一次有限验证。
- 给战斗设空间、限制与失误成本。
- 让配角对主角的态度随事实逐步变化，不轮流震惊。
- 将战力、身份、装备、知识和盟友交替作为奖励。

### 风险

- 敌人只负责送经验；
- 每次冲突都是低估、打脸、震惊；
- 升级后没有新选择，只是数字变大；
- 主角因面板无成本地全知全能。

## 3. 凡人生存经营

### 核心承诺

资源有限、修行漫长，主角靠谨慎、积累、劳动和关系经营逐步改变命运。

### 章节发动机

> 明确缺口 → 期限/价格 → 可选路径 → 权衡风险 → 行动 → 小幅结算

### 写法

- 明确钱粮、丹药、时间、岗位、债务、功法门槛和机会成本。
- 展示准备，让后续脱险成为兑现而非临时聪明。
- 用日常生活、工作和家庭关系承载修炼。
- 允许时间跳跃，但每次跳跃前设长期目标，跳跃后先结算变化。
- 让人情有经手人、成本和偿还方式。

### 风险

- 把“稳健”写成没有主动选择；
- 用重复盘算拖延行动；
- 逐笔记账却没有人物关系变化；
- 过度压低主角，使读者长期得不到兑现。

## 4. 家族群像

### 核心承诺

读者追随的不是单一主角，而是一个家族、宗门或共同体在代际中的兴衰与选择。

### 叙事单位

把“人物成长”升级为“共同体资产负债表”：

- 人口与继承；
- 功法、灵物与产业；
- 婚姻、盟约与仇怨；
- 地盘、供奉与附庸；
- 核心秘密和组织记忆；
- 不同代际的价值冲突。

### 写法

- 每次切换视角前明确该人物代表的利益与信息。
- 用议事、婚姻、资源分配、征战和继承推动群像，不平均分配戏份。
- 让上一代的决定在下一代兑现，形成长因果。
- 用称呼、座次、谱系、产业和仪式表现身份。
- 时间跳跃后先展示谁老了、谁长成、什么资源增减、关系如何改变。

### 风险

- 人名过密、人物只有职务没有性格；
- 家族永远意见一致；
- 用旁白年表替代场景；
- 新一代重复上一代的性格和冲突。

## 5. 民俗志怪

### 核心承诺

熟悉的乡土生活不断显露出不合常理的一角，人物以地方知识、人情和仪式面对未知。

### 章节发动机

> 日常秩序 → 微小异常 → 众人给出不同解释 → 异常扩大 → 规则/旧事显形 → 付出代价

### 写法

- 先建立饭桌、农活、街坊、丧葬、庙宇、河流等生活秩序，再让怪异侵入。
- 用方言词汇和地方习惯区分人物，但保证上下文能理解。
- 让民俗既可能是迷信，也可能含有生存经验。
- 恐怖前后保留烟火气、玩笑和亲情，使未知更有反差。
- 用一个稳定的视觉或声音意象作为异常锚点。

### 风险

- 为了“有味道”堆砌方言，降低理解；
- 日常闲笔没有伏线或人物功能；
- 怪物只靠外形吓人，没有行为规则；
- 每次都用童谣、红衣、纸人等通用符号。

## 6. 规则诡异冒险

### 核心承诺

人物进入未知环境，通过观察、试错、合作和牺牲理解规则并求生。

### 章节发动机

> 异常现象 → 初步假设 → 低成本测试 → 规则反噬/修正 → 团队执行 → 得到出口或新条件

### 写法

- 区分已观察事实、人物猜测和确认规则。
- 让规则尽快通过行动验证，不用说明书直接宣布。
- 给团队明确但可变化的功能：判断、战斗、工具、后勤、交涉、情绪支撑。
- 保留物资、伤势、时间和撤退路线。
- 在高压之间安排短暂温情或幽默，恢复读者感受力。

### 风险

- 规则恰好在需要时凭空出现；
- 专有名词和等级压倒人物；
- 团队成员只负责牺牲；
- 恐怖持续升级，没有节奏差和生活锚点。

## 7. 朝堂谍战悬疑

### 核心承诺

人物在身份、证据、阵营和制度之间求生，读者通过不断重读旧线索获得乐趣。

### 章节发动机

> 任务/案件 → 线索 → 多种解释 → 身份或利益冲突 → 验证/误导 → 局部真相 → 更深问题

### 写法

- 让线索具备表面意义和二次解释，但二次解释必须有旧证据支撑。
- 给每个阵营明确目标、权限、资源和信息盲区。
- 用公文、口供、账册、职位、礼仪和经手责任承载制度冲突。
- 让主角通过选择信息公开的时间和对象获胜，不靠全知。
- 每揭开一层真相，解决一个旧问题，同时产生一个可行动的新问题。

### 风险

- 所有人说话都像谜语；
- 真相依赖未出现过的信息；
- 阵营过多且名称相似；
- 主角永远正确，调查没有误判成本。

## 8. 现代制度修仙

### 核心承诺

把学校、公司、贷款、合同、考试、保险和平台规则与修炼结合，用熟悉制度解释陌生仙术。

### 章节发动机

> 现实需求 → 制度门槛 → 修炼方案 → 成本计算 → 竞争/考试/工作 → 资源与身份结算

### 写法

- 让仙术进入价格、合同、课程、岗位和社会阶层。
- 用现实制度作类比，但确保仙术仍有身体风险和奇观。
- 让讽刺来自规则自然运作，而不是作者持续吐槽。
- 把数据用于选择和代价，不把每章写成报表。
- 让贫富差距改变训练时间、风险承受力和信息渠道。

### 风险

- 热梗过多导致世界失去独立性；
- 所有角色只代表一种社会观点；
- 数据持续增长但情节不变；
- 主角只会吐槽，缺少主动行动。

## 9. 通用题材模式

当作品不是奇幻或仙侠题材时，从下面选择最贴近的主模式，再按需组合一个副模式：

### 都市/现实成长

核心承诺是人物在工作、家庭、金钱、身份或社会关系的具体压力下，靠能力与选择获得可见改变。让每章有一项现实任务、一个阻碍和一笔结算，避免把职场或生活写成泛泛鸡汤。

### 言情与关系推进

核心承诺是关系在吸引、误解、试探、选择和承担后发生变化。每场对话都应争夺情感、边界或承诺，避免只靠误会拖延冲突；关键情绪要有触发、累积、兑现与余波。

### 悬疑与推理

核心承诺是读者可以用已出现的证据重建真相。区分事实、假设和误导，让线索绑定人物动机、权限和代价；每次揭示既解决一个问题，又产生一个可行动的新问题。

### 历史与时代叙事

核心承诺是人物在制度、阶层、地域和时代变化中做出有代价的选择。历史细节应服务行动、身份或资源，不把正文写成资料汇编；涉及真实历史时避免把虚构情节伪装成史实。

### 科幻与未来冒险

核心承诺是人物使用一个有边界、有成本的技术或制度解决眼前问题，并因此进入更大的未知。先让设定通过使用接受验证，再逐步扩展世界，不用术语堆叠替代冲突。

### 轻喜剧与日常群像

核心承诺是人物在具体生活目标和关系摩擦中持续产生反差与变化。笑点来自性格、处境和选择的后果，不靠贬低弱者、重复热梗或打断主线。

## 10. 副模式与调味

副模式只能补足主模式缺少的阅读感受：

- 快升级＋民俗志怪：让怪物与环境更有地域性。
- 凡人生存＋家族群像：让个人积累跨代兑现。
- 朝堂谍战＋规则诡异：让案件规则可以被试验。
- 现代制度＋凡人生存：强化成本与资源压力。
- 任一主模式＋生活/关系：增加食物、住处、照顾、交易和称呼变化，缓冲高压。

不要同时叠加两个都需要大量解释的模式，例如家族谱系＋复杂规则空间＋现代金融体系。

## 11. 误配检查

写作前回答：

1. 本章主要让读者爽、怕、猜、感动、经营还是见证兴衰？
2. 本章的核心冲突能否由主模式自然产生？
3. 副模式是否帮助主问题，还是只展示作者知识？
4. 删除副模式内容后，本章是否反而更清楚？若是，删除。
